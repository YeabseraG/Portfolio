Online Shop

A responsive e-commerce platform developed with React, Next.js and TypeScript, featuring product search, dynamic routing, cart management and a complete checkout flow. The project demonstrates modern front-end development practices, component-based architecture and user-centered design principles.

View Live Site GitHub README

Project Description

Online Shop is a React and Next.js e-commerce application that allows users to browse products, search for items, view product details, add products to a cart and complete a checkout flow.

The project was created to practise component-based development, routing, state management, API fetching and user interaction in a modern JavaScript framework environment.
