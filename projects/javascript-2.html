Old Games Archive

A game archive application built with HTML, CSS and JavaScript. The project includes game browsing, searching, sorting, authentication, favourites and dedicated game detail pages.

View Live Site GitHub README

Project Description

OldGamesArchive is a front-end game archive i developed that allows users to browse a collection of games from a NOROFF API. Users can search for games by name, sort the list, view dedicated game pages and save their favourite games.

The project was created to practise JavaScript modules, API fetching, local storage, authentication flows and dynamic rendering. The goal was to create a functional and easy-to-use archive experience while keeping the interface clear and responsive.
