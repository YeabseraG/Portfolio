Semester Project 2

Auction House

A responsive auction marketplace that enables users to create listings, participate in auctions and manage their profiles through a dynamic, API-driven interface. The project showcases authentication workflows, real-time auction data handling, responsive layouts and user-centered front-end development practices.

View Live Site GitHub README

Project Description

AuctionHouse is an auction platform where users can browse auction listings, view individual listings, place bids, create listings and manage their profile.

The project was created to practise building a larger front-end application with authentication, API interaction, dynamic rendering and user-focused auction functionality.
